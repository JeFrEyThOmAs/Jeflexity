# SapienX 🔍

SapienX is a modern AI-powered search engine inspired by Perplexity AI.

It combines real-time web search, conversational AI, source-backed answers, intelligent follow-up questions, and smart autocomplete into a seamless AI-native search experience.

---

# ✨ Features

- 🔎 AI-powered real-time search
- 📚 Source-backed responses
- 🧠 Conversational follow-up questions
- ⚡ Smart autocomplete suggestions
- 🗂 Persistent conversation history
- 🔐 Secure authentication
- 🌐 Real-time web search integration

---

# 🏗 Tech Stack

## Frontend
Built using React, TypeScript, Bun, and Tailwind CSS to create a fast and responsive AI-native search experience with conversational UI, autocomplete suggestions, and dynamic search interactions.

---

## Backend
Built using Bun, Express, and TypeScript with a scalable API architecture for handling AI search workflows, conversation management, authentication, and persistent chat history.

---

## AI / Search
- LangChain LCEL Pipelines
- ChatPromptTemplate
- RunnableSequence
- StringOutputParser
- Gemini 2.5 Flash
- Tavily Search API

The project uses modern LangChain pipeline orchestration for structured prompt handling, conversational context management, reusable AI workflows, and response parsing.

---

## Database / Authentication
- Prisma ORM
- PostgreSQL
- Supabase Auth

Used for secure authentication, conversation persistence, and scalable database management.
